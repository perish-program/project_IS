# Проект внедрения информационной системы

## Назначение проекта
Веб-ориентированная автоматизированная информационная система для ведения электронных медицинских записей.
Система предназначена для автоматизации работы регистратуры и врачей, ведения картотеки пациентов, создания медицинских записей, а также предоставления пациентам доступа к своим направлениям и результатам анализов через личный кабинет.

## Как запустить
1. Клонировать репозиторий: `git clone <URL>`.
2. Развернуть веб-сервер (Apache/Nginx) и установить панель управления **OpenPanel версии 5.4.3**.
3. Импортировать структуру базы данных через phpMyAdmin (дамп базы находится в папке `src/db/dump.sql`).
4. Настроить конфигурационный файл подключения к БД (указать логин, пароль и имя базы данных).
5. Открыть панель в браузере и проверить работу системы. 
6. Запустить тесты, используя встроенные средства тестирования OpenPanel.
