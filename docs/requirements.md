# Требования к ИС
1. Учёт пациентов и ведение медицинских записей. Система должна обеспечивать регистрацию пациентов (создание картотеки), поиск по ФИО/полису, а также создание и хранение записей о приемах (жалобы, анамнез, диагноз, назначения).
2. Формирование отчётов и выписок. Система должна генерировать выписные эпикризы и результаты анализов в формате PDF (с поддержкой кириллицы), а также выгружать реестры (списки пациентов) в формате Excel (XLSX).
3. Интеграция с панелью управления сервером (Open Server Panel). Система должна быть развернута на веб-сервере с возможностью администрирования через панель управления (управление доменами, базами данных MySQL, настройка версии PHP и мониторинг логов ошибок).
