# Архитектура информационной системы

## Слои приложения
Клиентский слой: веб-браузер пользователя (тонкий клиент). Обеспечивает отображение интерфейса и ввод данных для врачей, регистраторов и пациентов.
Серверный слой: веб-сервер Apache (в составе OpenServer 5.4.3) с установленным фреймворком Laravel 7 (PHP 7.2.34). Обрабатывает бизнес-логику, маршрутизацию и права доступа.
Слой данных: реляционная база данных MySQL/MariaDB. Обеспечивает хранение структурированных данных (картотеки пациентов, медицинских записей, справочников), управление через phpMyAdmin или консоль.

## Компоненты
Модуль авторизации и разграничения прав доступа (RBAC).
Модуль управления пациентами (картотека).
Модуль ведения медицинских записей (ЭМЗ).
Модуль лабораторных исследований (с эмуляцией внешней ЛИС).
Модуль генерации отчетов (PDF/Excel).
База данных (MySQL/MariaDB).

## Интеграции
Система развернута в локальной сети медицинского учреждения. В рамках проекта реализована программная эмуляция интеграции с внешней лабораторной системой (прием результатов анализов в формате JSON/API). В перспективе предусмотрена интеграция с федеральной платформой ЕГИСЗ.
